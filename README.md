# Tiny C++ Quiz

A very small terminal quiz made for learning C++ and Git.

## Build and run

You need a C++ compiler such as `g++`.

```sh
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o quiz
./quiz
```

## Practice Git

Pick an issue, then try this workflow:

```sh
git switch -c feature/your-feature-name
# Edit main.cpp
git add main.cpp
git commit -m "Add your feature"
git push -u origin feature/your-feature-name
```

After pushing, open a pull request and ask a friend to review it.
